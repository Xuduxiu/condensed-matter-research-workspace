# 数据完整性与热点判断方法 V2.5

状态：生产数据审计口径<br>
审计日期：2026-08-09<br>
适用范围：CondMat Radar 的论文采集、跨源身份合并、开放获取下载与凝聚态热点分析

## 1. 结论先行

CondMat Radar **不能、也不应宣称数学意义上的“全网论文不重不漏”**。任何有限的数据源组合都受到收录范围、接口可见性、索引延迟、分页上限、撤稿与修订、预印本和正式版映射、元数据缺失、记录下线及访问权限的限制，因此无法从系统内部证明“全网全集”已经被穷尽。

V2.5 将目标改为可验证的工程承诺：

1. 对每个已声明的数据源、检索范围和时间窗口，记录查询版本、游标、水位线、分页结束条件、抓取状态和错误；不得静默截断。
2. 同一来源重复同步必须幂等；跨来源记录按稳定身份层级合并，并保留每个来源版本，不以合并结果抹去来源证据。
3. 缺页、失败页、身份冲突和低置信度匹配必须进入可追踪队列，不能被计作“已完成”。
4. 热点结论只有在样本量、摘要覆盖、来源混合、跨源重叠、新鲜度和实体抽取覆盖同时通过门槛后，才可描述为“凝聚态领域趋势”；否则只能称为“当前观测样本中的信号”。
5. 下载只覆盖合法、明确可用的开放获取路径。能检索到元数据不等于拥有合法 PDF 下载权。

## 2. 数据对象与统计范围

### 2.1 三层对象

- **canonical paper（规范论文）**：分析和去重所用的逻辑论文身份。
- **paper version（来源版本）**：arXiv、OpenAlex、Crossref、出版社等分别提供的记录或版本；必须保留来源、来源 ID、抓取时间、原始字段和版本关系。
- **source observation（抓取观测）**：一次带查询参数、游标、时间和状态的采集事实，用于证明某次同步究竟覆盖了什么。

一篇规范论文可以对应多个来源版本；来源版本数不能用规范论文数替代。跨源重叠率必须由来源版本关系计算，不能仅查看规范论文上的单个 `source` 标签。

### 2.2 范围必须显式标注

以下范围不得混用：

- 全库真实论文数；
- 满足凝聚态分类规则的可分析子集；
- 某个来源在某个时间段内的返回集合；
- 当前窗口与相邻基线窗口；
- 有摘要、可抽取主题、可识别材料或方法的子集；
- 具有合法开放获取 PDF 候选的子集。

所有图表必须显示数据截止时间、窗口、来源、分母和质量状态。缺失值不得默认当作“无该主题/材料/方法”。

## 3. 可审计覆盖，而非“全网完整”

每个来源和查询分片至少记录：

- provider、接口或数据快照版本、查询表达式及学科过滤规则；
- 时间范围、分页大小、游标或 offset、水位线和预期终止条件；
- 请求次数、原始返回数、有效记录数、新增数、更新数、重复数和拒绝数；
- `COMPLETE`、`PARTIAL` 或 `FAILED` 状态及错误分类；
- 首末记录时间、同步开始/结束时间和最后成功新鲜度；
- 可重放的运行 ID、日志或审计记录。

只有到达来源声明的终止条件且全部页成功，分片才可记为 `COMPLETE`。`PARTIAL` 或 `FAILED` 不得推进完成水位线；下一次运行必须从最后一个已确认游标继续。来源 API 自身的收录盲区仍需明确列为外部限制。

### 3.1 全领域候选流与严格分析资格

V2.5 将“尽量不漏候选”和“避免污染热点分母”拆成两个可审计层级：

- **OpenAlex 全领域候选层**：按日期窗口请求 `topics.subfield.id:3104`（Condensed Matter Physics），覆盖 article、preprint 与 review，并用 cursor 消耗窗口内全部分页。API 返回的每条候选都保留为来源版本和采集证据；弱标签候选不会被静默丢弃。只有游标正常终止，窗口才可记为完整。
- **严格分析资格层**：候选还必须通过本地标题/摘要/期刊文本规则，或具有足够强的 OpenAlex 凝聚态主题证据（主主题属于 3104 且分数至少 0.35，或任一 3104 主题分数至少 0.45），才设置 `condmat_view_eligible=1`。未通过者仍保留在库中，标记为 `openalex-field-candidate-unverified` 并进入复核口径，但不进入热点、材料和方法图表；后续新证据可以提升其资格。
- **arXiv 预印本层**：独立扫描全部 9 个 `cond-mat.*` 分类，用于补足预印本时效性，并保留主分类及版本信息。
- **Crossref 正式出版交叉校验层**：当前按游标分页扫描配置的 18 本精选期刊（core 范围可取其子集），用于核对 DOI、正式出版日期、期刊与许可等元数据。该 18 刊集合是有意限制的交叉校验样本，**不是全凝聚态期刊集合，也不能充当全领域分母**；Crossref 未命中不能解释为论文不存在。

因此，覆盖审计同时报告“宽收集候选数、严格 eligible 数、待复核候选数和各来源分页完成状态”。全领域候选流提升召回，不会自动放宽热点图表的质量门槛。

建议同时报告以下覆盖指标：

- 各来源记录量和占比；
- 稳定身份覆盖率；
- 来源两两交集、Jaccard 相似度和三源以上交集；
- 跨源规范论文覆盖率；
- 按月份和来源的缺口热力图；
- 摘要、主题、材料、方法、引用和 OA 字段覆盖率；
- 采集延迟分布与最后成功同步时间；
- 待重试页、身份冲突及人工复核积压。

## 4. 去重身份层级

自动合并按以下优先级执行：

1. 规范化 DOI 精确一致；
2. 基础 arXiv ID 精确一致，版本号仅作为来源版本属性；
3. OpenAlex ID 精确一致；
4. 严格规范化标题、第一作者和年份一致，或年份仅允许相邻偏差且其他字段达到严格阈值。

约束如下：

- DOI 冲突的记录不得自动合并；
- 标题相近但作者不一致、短标题或通用标题不得仅凭模糊相似度合并；
- 预印本与正式发表版可关联为同一规范论文，但必须保留两条来源版本及版本类型；
- 低置信度匹配进入 `identity_match` 人工复核，不得为了降低重复率强行合并；
- 每次合并必须保留所用规则、置信度、输入 ID 和时间，且可以回滚。

因此，“不重”应被解释为：在声明的身份规则下，已知稳定标识重复可幂等消除，模糊冲突可审计；它不等于系统能够证明不存在任何未知重复。

## 5. 合法开放获取下载边界

下载候选仅来自明确合法的开放获取路径，例如：

- arXiv PDF；
- 元数据明确标记为 OA 的出版社或仓储位置；
- OpenAlex 的 OA locations；
- Crossref 元数据中带开放许可的 PDF 链接；
- Unpaywall 返回的合法 OA location。

系统不得绕过登录、订阅、付费墙、验证码、访问控制或站点限制。只有通过 PDF 文件头、EOF、PyMuPDF 可解析、至少一页且未加密等结构校验后，任务才可记为成功。所有失败必须区分为无合法 OA、链接失效、网络错误、限流、非 PDF、损坏文件或解析失败，并保留尝试链路。

因此“保证能找到的论文就能下载”只能落地为：**对发现的每一个合法 OA 候选都穷尽受支持的合法下载路径并给出可审计结果**；付费或没有公开全文的论文只能保存元数据、DOI 和可访问入口，不能计作系统下载故障，也不能承诺获得 PDF。

## 7. 为什么暂时不能得出“全领域热点”结论

当前数据同时触发多项致命混杂：

1. 当前窗口 1,300 篇、基线 419 篇，量比 3.10，已经超出可比区间。增长可能来自补录、来源切换或过滤规则变化，而不是科研活动增长。
2. 来源混合偏移 67.8%，远高于 15% 门槛。不同来源的学科覆盖、摘要率和发布日期口径不同，来源份额变化会直接制造伪热点。
3. 跨源重叠为 0%，无法用多来源相互印证记录，也无法可靠评估漏收和重复。
4. 新鲜度滞后 25 天，“近期”图表系统性遗漏最近约三周半，无法承担实时热点判断。
5. 摘要覆盖仅 43.6%。关键词、材料和方法抽取偏向那些恰好提供摘要的来源、期刊和年份。
6. 主题覆盖当前 69.5%、基线 55.4%，基线未达门槛；材料和方法两窗均远低于门槛。比较份额或增速时，分母及可观测概率不一致。

在这些问题修复前，可以展示原始数量、覆盖率和“当前观测样本信号”，但必须附加 `source_mix_confounded`、`insufficient_coverage`、`stale_data` 等质量标签。不得使用“凝聚态整体正在转向”“全领域增长最快”或“真实热点排名”等措辞。

## 8. 热点发布的严格验收门槛

只有以下条件全部满足，`hotspot_reliable` 才能为真：

- 当前窗口与相邻基线窗口各不少于 100 篇；
- 当前/基线记录量比处于 0.50–2.00；
- 摘要覆盖率不低于 70%；
- 来源混合偏移不高于 15%；
- 最新数据滞后不超过 3 天；
- 至少 3 个独立来源有有效版本数据，跨源规范论文覆盖率不低于 25%；
- 主题、材料和方法分别在当前与基线两窗均达到 60% 覆盖，且两窗覆盖差不超过 15 个百分点；
- 所有参与窗口的来源分片均为 `COMPLETE`，不存在静默分页上限，`PARTIAL`/`FAILED` 未推进水位线；
- 稳定身份覆盖率不低于 99%，DOI 冲突未被自动合并，身份冲突和人工复核量被单独报告；
- 抽取器版本、词典版本、别名归并规则和输入哈希固定且可重放；当前与基线使用同一版本处理。

下载质量与热点可靠性分开验收：每个合法 OA 候选都必须产生成功文件或明确失败分类；成功文件必须通过结构校验。下载成功率的分母必须是“存在合法 OA 候选的论文”，不能把付费论文从失败率中隐去，也不能把它们错误计为下载失败。

任何一项未通过时，图表应显示具体失败门槛，并自动降级为探索视图；不得只隐藏警告而继续发布全领域排名。

## 9. 数据修复顺序

按依赖关系执行，避免在错误分母上反复重算图表：

1. **冻结审计快照**：保存数据库路径、备份或哈希、查询口径、截止时间和上述指标，确保后续变化可比较。
2. **恢复来源版本层**：从现有 182,230 篇规范论文的来源字段和原始标识回填 `paper_versions`，但不凭弱匹配制造跨源关系。
3. **完成多源历史回填**：按来源、月份和学科分片补齐 arXiv、OpenAlex、Crossref；验证游标终止条件，失败分片保持未完成。
4. **重建身份映射**：优先 DOI、基础 arXiv ID、OpenAlex ID，再执行严格标题—作者—年份匹配；冲突进入人工复核。
5. **修复实时水位线**：先补齐最近 25 天，再建立增量扫描、重试和延迟告警，使新鲜度稳定达到 3 天以内。
6. **补齐摘要与结构化元数据**：从合法来源回填摘要、作者、日期、学科、引用和 OA 状态，先达到 70% 摘要门槛。
7. **统一重跑实体抽取**：用版本化模型/词典对当前和基线同时重算主题、材料和方法；归并化学式、全称、缩写和拼写变体，缺失保持未知。
8. **校正来源偏移**：在来源覆盖可比后重建相邻窗口；必要时按来源分层展示并进行透明加权，但不得用权重掩盖原始覆盖差异。
9. **重算质量门槛**：核验来源重叠、来源混合、窗口量比、新鲜度和三类抽取覆盖；保存通过/失败证据。
10. **再发布热点结论**：仅在 `hotspot_reliable=true` 时生成凝聚态整体排名；同时展示来源分层、置信区间、绝对量与份额变化。
11. **独立执行 OA 下载**：对规范论文聚合合法 OA 候选、逐级尝试并验证 PDF；将下载可得性作为单独维度，不反向改变热点样本。

## 9.1 实时水位线与历史回补窗口

两种扫描模式承担不同职责，不能共用同一个增量日期窗口：

- `live` 只从最后一次**所有启用来源均完整成功**的安全水位线扫描到当天；任一来源或期刊分页失败时不推进水位线，下一轮重放重叠区并依赖规范身份去重。
- `full` 使用固定的包含首尾日期窗口：`today - (full_lookback_days - 1)` 到 `today`。API 默认 180 天，允许 30–3650 天；系统页提供 180 天和 730 天预设。
- 180 天预设用于覆盖 90 天当前观察窗与相邻 90 天等长基线，便于补齐同一时间范围内的多源版本。它只是回补范围，不代表已经达到同源可比性；仍须通过来源重叠、来源混合和窗口样本门槛。
- 730 天预设用于更长期的来源版本和摘要回补，耗时与远程请求量明显增加，不应用来暗示“全网不重不漏”。OpenAlex、Crossref 和 arXiv 各自仍有收录范围、更新时间和接口限制。
- 抓取 checkpoint 由来源、范围和 `date_from/date_to` 共同区分；同一固定窗口可断点续跑。日期滚动后会形成新窗口，不能把前一天的完成状态误当成新窗口完成。

预检 180 天窗口而不写数据库：

```http
POST /api/daily/run
Content-Type: application/json

{
  "apply": false,
  "scan_mode": "full",
  "full_lookback_days": 180,
  "skip_network": true
}
```

响应、排队状态、运行进度和最终 `report_json` 均保存 `date_from`、`date_to`、`window_policy` 与 `historical_days`，使图表使用的数据窗口可以复核。

## 10. 正确反映热点的图表口径

通过验收后，热点图表至少同时提供：

- 绝对论文数、占全体份额和相对基线变化，避免只看增长率；
- 来源分层结果及合并结果，暴露来源偏差；
- 按周/月的滚动趋势和置信区间，避免单日噪声；
- 主题—材料—方法联合矩阵，而不是仅靠预设材料列表；
- 新进入、持续升温、稳定和降温四类状态，并设置最小样本门槛；
- 摘要覆盖、抽取覆盖、新鲜度和来源混合作为图表旁的质量条；
- 预印本与正式发表版去重后的主图，以及来源版本变化的辅助图；
- 撤稿、更正和版本更新的单独标记。

允许的结论示例是：“在通过质量门槛的 90 天可比样本中，主题 X 的论文份额相对相邻基线上升 Y 个百分点。”未通过门槛时只能写：“在当前观测样本中出现 X 信号；由于来源偏移、摘要缺失或数据滞后，不能外推至凝聚态整体。”

## 11. 可复核证据

每次对外展示或导出热点报告时，应一并保存：

- 覆盖审计：`GET /api/library/coverage?refresh=true`；
- 90 天分析：`GET /api/ui-v2/analytics?days=90`；
- 下载统计：`GET /api/library/downloads/statistics`；
- 单任务下载审计：`GET /api/library/downloads/{task_id}/audit`；
