# Radar Web v2.3：全链路实装与可用性加固

日期：2026-07-17

## 结论

Radar Web v2.3 已把论文发现、实时扫描、材料证据、统计洞察、立即下载、Zotero 导出、监控与 DeepSeek 分析收敛到同一个六导航 React 工作台。页面不再用占位统计掩盖生产状态；缺失、失败、等待复核和数据日期延迟均直接显示真实值。

## 本轮实装

### 首页与统计洞察

- 今日入库与“最新有数据日”分开统计，避免论文源尚未发布时首页全部显示 0。
- 首页展示最新数据日论文、预印本、正式见刊、近 7 日论文、监控命中、下载与人工复核。
- “统计洞察”作为首页内部视图，保持总览、发现、文献库、材料雷达、监控、系统六个主导航不变。
- 新增 7/30/90/180/365 日窗口、论文时间线、来源分布、期刊排行、下载结构、摘要/OA/PDF 完整度、监控趋势和论文证据材料榜单。
- ECharts 与非首屏页面按需加载；初始 JS 为 183.80 kB（gzip 59.91 kB），相较重构前约 1.29 MB 减少约 86%。

### DeepSeek

- 旧下载工具中的密钥已迁移到 `G:\condmat-trend-radar\secrets\.env.local`，未写入仓库、未输出密钥内容；原 txt 暂保留。
- 系统页显示配置状态、API 地址和 fast/pro 模型；论文详情提供单篇证据约束解读。
- 统计洞察提供手动生成的雷达简报，GET 只读缓存，POST 才会调用模型，避免后台自动消耗额度。
- 简报只使用当前时间窗内的真实凝聚态论文标题、摘要、材料与主题，严格校验引用论文 ID 并缓存到本地数据库。
- 生产实测：7 日、5 篇证据首次调用 93.2 秒成功；缓存读取 18 ms。

### 实时扫描与监控

- 后台实时扫描线程确认运行，默认每 300 秒检查一次 arXiv cond-mat。
- 自动规则只评估本轮新增或实质更新论文，旧高分结果不再挤占新命中；手动执行仍支持全库最新优先。
- arXiv 版本 ID、submitted/updated 日期和 fetched/kept/updated/deduped 计数语义已修正。
- 监控规则支持创建、暂停/启用、立即执行、OA 自动下载与删除；浏览器已用临时规则完成创建和删除闭环，生产库恢复 0 条规则。

### 下载、摘要与 Zotero

- 发现页跨页选择最多 100 篇，支持全选、清空与批量“立即下载并导出 Zotero”；批次状态持久化，刷新页面仍能继续查看。
- 文献库批量下载改为真实后台批次并轮询最终结果，不再只显示队列已接受。
- 下载解析合并 canonical 与版本元数据；Unpaywall 单源异常不再阻断其他合法 OA 候选。
- 摘要补全新增持久退避、来源轮换与 Semantic Scholar 429 冷却，避免每次扫描重复打失败来源。
- 生产实测：1 篇已有 PDF 的批次完成 1/1、失败 0；RIS 与 ZIP 均 HTTP 200，RIS 含 `file:///` 本地 PDF，Zotero 包含 1 个附件。

### 论文派生材料

- 材料页只展示有真实论文证据的动态实体，支持服务端搜索、分页与 100 行视图，不再靠固定预设列表填充。
- 修复 `AgBeF4_4`、`AgBeF4_5` 多晶型标签误识别为 `AgBeF44/45`；真正的 `SrTiO_3`、`Bi_2Te_3` 下标仍正确保留。
- 已只重扫受影响论文 `arxiv:2607.08372v1`，当前链接为 Ag2F7、AgBeF4、AgF2、cuprate，不含错误变体。
- 两个旧错误实体目前为零链接孤儿，保留待审计，没有未经确认地删除历史数据。

### 系统状态与性能

- 系统页展示 8.4 GB 生产 SQLite、quick_check、外键、FTS、PDF、工作台、下载、迁移、DeepSeek、每日任务和脱敏运行日志。
- 大库完整健康检查后台执行并缓存 24 小时，系统页不再被 9 GB quick_check 长时间阻塞。
- 材料查询合并重复扫描并加入线程安全 30 秒缓存；Dashboard/Materials 使用 single-flight、深拷贝和 128 项上限。
- 生产实测：
  - Dashboard 冷查询 5.705 秒，缓存 9 ms；
  - `materials?q=MoS2` 冷查询 221 ms，缓存 4 ms；
  - 7 日统计 1.844 秒；
  - 生产库 185,388 canonical papers、185,392 versions、27 个唯一 PDF，quick_check 为 ok。
