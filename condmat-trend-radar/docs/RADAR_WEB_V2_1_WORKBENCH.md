# Radar Web v2.1 · 工作台使用说明

## 启动

在项目根目录运行 `paper.cmd` 或 `paper.ps1`，然后访问前端地址。系统页应显示 API 在线、数据库路径以及 `radar_workbench_v2`。

## 最短使用路径

1. 在“发现”输入题名、材料、作者或 DOI。
2. 先用“本地元数据”；需要补充新论文时切换“远程论文源”或“本地 + 远程”。
3. 远程论文先浏览，不自动污染本地库；点击“保存”才导入，点击“加入下载队列”会导入并排队。
4. 在论文详情中收藏、标记稍后阅读、写笔记，或直接加入专题。
5. 在“文献库”按收藏、稍后阅读、PDF、失败任务、人工复核或专题筛选。
6. 点击“处理下载队列”；有合法 OA PDF 时会校验并存储，没有时保留明确失败原因和来源链接。
7. 已下载论文可在详情中“打开 PDF”，文件通过受控 API 内联提供，不暴露任意本地路径。
8. 需要 Zotero 时导出 RIS；本地 PDF 存在时会保留附件关联。

## 数据与安全边界

- 本地 SQLite 是唯一状态源；远程搜索结果未明确保存前不写库。
- 合并优先级：DOI → arXiv ID → 规范化标题 + 首位作者。
- 下载器只接受合法开放获取位置，并验证 HTTP 类型与 PDF 文件头。
- 收藏、稍后阅读、笔记和专题是增量表，可独立清理，不改变论文身份模型。
- 所有写操作进入 `user_action_log`，便于排查误操作。

## 外部源行为

三源并行且彼此隔离：某一来源超时或配额失败时，其余来源仍可返回，界面会显示每个来源的状态和错误摘要。远程首屏默认最多 18 条，以优先保证交互速度。

## 已知限制

当前监控仍缺少编辑、启停、立即执行和命中历史；下载队列暂无取消；PDF 暂不支持标注；外部来源的覆盖率、访问策略和开放获取状态由其上游数据决定。
