CondMat Radar 2.4.0 - Windows x64

Public release: no API keys, database, PDFs, logs, or personal history are included.

Normal install:
1. Double-click install.cmd.
2. Wait for the browser to open http://127.0.0.1:8765/.
3. Use the desktop shortcut afterward.

Private lab handoff:
Use the separately generated PRIVATE_Sister_Install_Kit folder and double-click
"一键安装_使用我的API.cmd". Delete that private folder after installation because it
contains the owner's API configuration.

Program: %LOCALAPPDATA%\Programs\CondMatRadar
Data:    %LOCALAPPDATA%\CondMatRadar\data
Config:  %LOCALAPPDATA%\CondMatRadar\config\.env.local

No administrator account, Python, Node, npm, or firewall rule is required.
See docs\WINDOWS_INSTALL_HANDOFF.md for the full Chinese instructions.
